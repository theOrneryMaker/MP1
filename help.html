MP1 Macropad Guide

Everything the macropad, its menus and the web tools can do.

Overview

The MP1 Macropad is a programmable input device with 8 keys, a rotary encoder, and an OLED display. It can type text, run keyboard shortcuts, control media, open applications, and more.

Terms Used

The macropad, this guide and the web pages use the same words for the same things:

EncoderThe rotary control. Turn it; click its button (a short press), long press it, or hold + turn it.
Home layerThe layer active at power-up (exactly one). The HOME LAYER gesture jumps back to it. In keymap.js it's the layer with "default": true.
Secret 1 / Secret 2Hidden layers, opened with the TOG SEC 1 / TOG SEC 2 gestures.
MacroA key action made of several steps (typing, keys, combos, waits). In keymap.js it's a "sequence".
Layers menuThe list of layers a click opens. Layer keys shows them on the keys instead.
Settings menuWhat a long press opens: TIMER, STOPWATCH, VARIABLES, GESTURES, SCREEN, LIGHTS, SOUND, CONFIGURATOR, ABOUT.
VARIABLESThe Settings submenu with timings and speeds (press times, timeouts, encoder speed, key repeat, hold-to-confirm, menu rolling).
Lights / LED stripLIGHTS is the menu; the LED strip is the optional hardware it controls.
Sound / buzzerSOUND is the menu; the buzzer is the optional hardware it controls.
Export / ImportSaving a single key or layer to a file to share, and adding one from a file. Save / Open are for the whole keymap or settings file.

Basic Controls

The Encoder

Turn: Performs the clockwise or counter-clockwise action set for the current layer (volume, scrolling, zoom, tabs, arrow keys, etc.)

Press:

  • Click (< 0.4s): Opens the Layers menu (after a brief pause to check for a double or triple click)
  • Double click: Layer keys: press a key to jump to that layer (default; change in GESTURES)
  • Triple click: Opens the timer (default; change in GESTURES)
  • Medium press (0.4-1.5s): Exits current menu (outside a menu, briefly shows the current layer name)
  • Long press (> 1.5s): Opens Settings menu

Turn while holding:

  • Hold + turn clockwise: Toggle mouse jiggle on/off (default; change in GESTURES)
  • Hold + turn counter-clockwise: Toggle secret layer (default; change in GESTURES)
  • Click, then hold + turn clockwise: Stopwatch (default; change in GESTURES)
  • Click, then hold + turn counter-clockwise: Nothing by default (pick a function in GESTURES)

The 8 Keys

Each key can be programmed to:

  • Type text or passwords
  • Execute keyboard shortcuts
  • Open URLs
  • Launch applications
  • Control media playback
  • Scroll, move the mouse, or click mouse buttons
  • Run complex macros

The OLED display shows icons or labels for what each key does.

Layers

Layers are different "pages" of key assignments. Think of them like function keys on a keyboard - the same physical keys do different things on each layer.

Switching Layers

  1. Click the encoder
  2. Turn the encoder to select a layer
  3. Click again to switch to that layer

The Layers menu closes by itself after 5 seconds without input (adjustable with LAYERS T O in VARIABLES).

All scrolling menus (Layers, Settings, VARIABLES and the other settings menus) roll like a slot-machine reel: as you turn, the items slide up or down one place, growing as they reach the middle and shrinking as they leave it, with the next items sliding in from the edge.

Dial in the feel with two settings in VARIABLES:

  • ROLL TIME - How long one roll takes (0-0.4s, default 0.15s). Lower is snappier, higher is more visible. 0 turns the animation off.
  • ROLL STEPS - How many frames are drawn during each roll (1-8, default 4). More is smoother. 1 gives a single half-way frame.

The screen can draw roughly 30-40 frames a second. If ROLL STEPS asks for more than that within ROLL TIME, some frames are skipped, but the roll still takes the same time. As a guide, ROLL TIME ÷ ROLL STEPS should be about 0.03s or more (for example 0.15s with 4-5 steps, or 0.24s with 8). Spinning the encoder quickly restarts the roll on each click, so fast scrolling stays fast.

Layer Keys (quick jump)

A faster way to switch layers: set any gesture (for example TRIPLE CLK) to LAYER KEYS in GESTURES. The gesture shows each layer's name on a key; press that key to jump straight to the layer.

  • Names are cut to 4 letters. The current layer is marked with > (for example >MED).
  • Layers are in the same order as the Layers menu. Secret layers are never shown.
  • With more than 8 layers, the top line shows the page (LAYERS 1/2). Turn the encoder to change page.
  • Keys with no layer do nothing. Press the encoder to leave without switching. It also closes after the LAYERS T O time.

Example layers:

  • LOGINS: Quick access to credentials and password manager
  • DATA: Text snippets, formatting shortcuts
  • MEDIA: Media controls and volume
  • MACROS: Complex macros

Settings Menu

Access advanced features and tools.

Opening Settings

Long press the encoder (hold for 1.5+ seconds)

Settings Options

  • TIMER - Opens the countdown timer
  • STOPWATCH - Opens the stopwatch (see Stopwatch)
  • VARIABLES - Adjust timing and behavior settings
  • SCREEN - Screen saver timing and the Caps Lock indicator (see Screen Saver and Caps Lock Indicator)
  • GESTURES - Choose what double click, triple click, hold + turn and click-then-hold + turn do, and the click timing (see Encoder Gestures)
  • LIGHTS - LED strip: default scene, colours, brightness, animation speed and LED count. Only listed when an LED strip is switched on in settings.js (see Add-ons).
  • SOUND - Buzzer: key click, layer tone, start-up tone, volume and buzzer type. Only listed when a buzzer is switched on in settings.js (see Add-ons).
  • CONFIGURATOR - Opens the web-based keymap configurator
  • ABOUT - Opens the help documentation
  • EXIT - Close the settings menu

Navigation

  • Turn encoder: Scroll through options
  • Click: Select the highlighted option
  • Medium press: Exit settings menu

The Settings menu closes by itself after 10 seconds without input (adjustable with SETTINGS T O in VARIABLES).

Timer

A productivity timer built into your macropad.

Opening the Timer

  1. Long press encoder → Settings menu
  2. Turn to TIMER and click to open

Timer Controls

The keys become timer controls:

1HR30M15M5M
CLRPLAYPAUS---
  • 1HR / 30M / 15M / 5M: Set the timer to that preset (stops any running countdown)
  • CLR: Clear the timer to 0:00
  • PLAY: Start the countdown, or resume it after a pause
  • PAUS: Pause the countdown at its current time (PLAY resumes it)
  • ---: Not assigned

Encoder actions in timer:

  • Turn: Add or subtract 30 seconds (only while the timer is stopped)
  • Press: Exit the timer screen (the countdown keeps running)

The top-left corner shows the timer state: +/- (stopped, adjustable), RUN or PAUS. The countdown appears in the top bar on every layer while a time is set. The timer screen closes by itself after 30 seconds without input.

When Timer Completes

The display flashes "DONE" on a blank screen, closing any open menu. With the add-ons fitted, the buzzer beeps until you dismiss the alert and the LED strip flashes red.

  • Single tap encoder: Dismiss alert and return to last layer (timer clears to 00:00)
  • Double tap encoder: Dismiss alert and return to timer menu (the taps must be within CLICK TIME, set in GESTURES)
Note: During the alert, all keys and encoder rotation are blocked until you press the encoder.

Stopwatch

Counts up from zero. Open it from Settings → STOPWATCH, or assign STOPWATCH to a gesture in GESTURES.

The time shows large in the middle (12:34.5, or 1:02:03 after an hour). The bottom row of keys are the controls, in the same places as on the timer screen:

----
RSTPLAYPAUS-
  • RST: Stop and reset to 00:00.0
  • PLAY: Start, or resume after a pause
  • PAUS: Pause at the current time
  • Encoder press: Leave the stopwatch screen. It keeps counting in the background.
  • While the stopwatch has time on it, the top bar on every layer shows it (for example SW 1:15, or SW 1:02h after an hour). If a timer countdown is set, the countdown shows instead.
  • The SW ST/PAUS gesture starts or pauses the stopwatch without opening its screen.
  • The screen stays open while the stopwatch is running. When it's stopped or paused, it closes after 30 seconds without input.
  • It stays accurate for runs of any length, until the macropad is unplugged or restarted.

Screen Saver

OLED screens slowly burn in if they show the same thing for hours. When the macropad sits idle, the screen first dims, then turns off. Any key, turn or press brings it back.

Settings

Long press encoder → Settings → SCREEN:

  • DIM AFTER - Minutes idle before the screen dims (0-120, default 5; turn down to 0 for NEVER)
  • OFF AFTER - Minutes idle before the screen turns off (0-240, default 20; 0 = NEVER)
  • DIM LEVEL - Brightness while dimmed (0.05-1, default 0.1). How much difference this makes varies between screens.
  • LEDS OFF - The LED strip goes dark when the screen turns off (default ON; only matters with the LED add-on)
  • CAPS BOX / CAPS FLASH - Caps Lock indicator (see Caps Lock Indicator)
  • RESET DFLT / EXIT

Waking It Up

  • While dimmed: keys, the encoder and the button work as normal and brighten the screen.
  • While off: the first key, turn or press only wakes the screen and does nothing else, because you can't see which layer you're on. Press again to use it.
  • Mouse jiggle and the timer counting down don't count as activity, so the screen still sleeps while they run.
  • The screen never sleeps while the timer alert is showing (the alert also wakes it) or while the stopwatch screen is open and running.

Start-up Screen

While the macropad starts, the screen shows the start-up image, boot.bmp from the CIRCUITPY drive, for at least 1.5 seconds.

  • Your own image: replace boot.bmp with any black-and-white BMP up to 128 × 64 pixels (it's centred). In Windows Paint: resize the canvas to 128 × 64, draw, then Save as → BMP picture and choose Monochrome Bitmap. If the file is missing or can't be read, a plain MP1 title shows instead.
  • For testing: set "boot_debug": true (Settings Editor → Screen → Show debug text at start-up) to see the start-up messages instead of the image: how many layers loaded, the LED strip and buzzer, free memory and the watchdog.
  • How long: "boot_screen_seconds" (Settings Editor → Start-up screen time, default 1.5; 0 = no wait). Start-up errors still show on their own screen afterwards, either way.

Locking the Keys

Set any gesture to LOCK KEYS in GESTURES (or the Settings Editor). Using it locks the macropad, for cleaning, carrying it, or when something is resting on it:

  • The screen shows a full-screen LOCKED page that flashes between white-on-black and black-on-white (in time with the jiggle J / CAPS box), with a reminder of how to unlock, e.g. HOLD+TURN CW: UNLOCK.
  • Keys, encoder turns, clicks and all other gestures do nothing. Anything held down when you lock is released.
  • Unlock with the same gesture.
  • Still working while locked: the timer alarm (after dismissing it you're back on the lock page), mouse jiggle and the screen saver (the flashing page dims and turns off like any other).
  • If no gesture is set to LOCK KEYS any more (changed while locked), a long press unlocks, so it can't get stuck. Restarting the macropad always unlocks.

Hold-to-Confirm Keys

For keys you don't want to hit by accident (shut down, delete, send, a password): tick Hold to confirm on the key in the Keymap Configurator (or add "confirm": true to the key in keymap.js).

  • Press and hold the key: the screen shows HOLD, the key's icon and a bar that fills up.
  • When the bar is full, the key's action runs once, as a quick press, and the layer comes back. Keep holding or let go, it doesn't run again.
  • Let go early (or press the encoder) to cancel: nothing is sent.
  • How long to hold: CONFIRM T in the VARIABLES menu (0.2-3.0s, default 0.6s), the same for every confirm key.
  • While the bar fills, other keys and the encoder do nothing. A timer alarm takes over and cancels it.
  • A confirm key can't also repeat while held (the configurator hides that tick box; the start-up check reports both being on and uses confirm).

Caps Lock Indicator

The macropad shows when Caps Lock is on, whichever keyboard turned it on. Computers send the Caps Lock state to every connected keyboard, so this works on any computer with nothing to install.

  • CAPS box: While Caps Lock is on, a white box with black CAPS text shows at the right of the top bar. It blinks to white text on black and back, at the same rate and in time with the jiggle J (display_jiggle_blink_rate in settings.js). It's shown on every layer and on the timer, stopwatch and Layer Keys screens, and hidden while a menu is open.
  • Flash: When Caps Lock changes, CAPS ON or CAPS OFF flashes briefly on the layer screen; the CAPS box appears once the pop-up has gone. It doesn't flash while a menu or the timer/stopwatch screen is open, or while the screen saver has the screen off (it won't wake the screen).
  • Switch each one on or off in Settings → SCREEN: CAPS BOX and CAPS FLASH (both ON by default).
  • If Caps Lock is already on when the macropad starts, the box shows without a flash.

Add-ons: LED Lights & Buzzer

Both are optional. A macropad without them works exactly the same, and their menus (LIGHTS and SOUND) stay hidden. Switch each one on in settings.js (edit it from your computer, then restart the macropad); its menu then appears in Settings.

LED Strip

  • Wiring: NeoPixel (WS2812) data on GP19
  • Enable: in settings.js set "led_count" to the number of LEDs (e.g. 4). 0 means no strip and hides the LIGHTS menu.
  • Adjust: long press → Settings → LIGHTS:
    • SCENE - the scene on every layer that has no lights of its own (table below)
    • COLOR 1 / COLOR 2 - colours used by the scene
    • BRIGHTNESS - 0.05 to 1.0
    • SPEED - animation speed, 1 (slow) to 10 (fast); 5 is the middle. At 5 a pulse takes 3 seconds; 1 is three times slower, 10 four times faster.
    • LED COUNT - number of LEDs on the strip; applies as soon as you save (setting 0 switches the strip off and hides LIGHTS)
    Changes preview live while you turn and save when you press; if the menu times out mid-edit, the change is undone.
SceneEffect
STATICSolid colour 1
BREATHINGColour 1 fades in and out, then colour 2
REACTIVEColour 1, flashing colour 2 on each key press
PULSEColour 1 rising and falling
TWINKLEEach LED drifts on its own between dim and bright colour 1
LIGHTNINGFlickering strikes of colour 1 every few seconds (about 2-8 s apart at SPEED 4)
STROBEFast flashes of colour 1
RAINBOWMoving rainbow across the LEDs
CYCLEWhole strip blends through the spectrum
OFFLEDs off

COLOR 1 / COLOR 2 choose from 18 palette colours; BRIGHTNESS is 0.05-1.0; SPEED is 1 (slow) to 10 (fast). When the timer finishes, the strip flashes red until you dismiss it.

Fades stay smooth even at low brightness: the macropad applies BRIGHTNESS itself and smooths the steps between the strip's levels by alternating them from frame to frame, so slow pulses and breathing glide instead of stepping. The very dimmest levels are left unsmoothed so they don't shimmer.

Buzzer

  • Wiring: GP17
  • Wiring detail: buzzer + to GP17, – to GND
  • Enable: in settings.js set "buzzer" to "passive" (plays tones; most small 2-pin piezo buzzers) or "active" (fixed pitch, sounds on its own when powered). "none" hides the SOUND menu. For an active buzzer that sounds when the pin is low, also set "buzzer_active_low": true.
  • Adjust: long press → Settings → SOUND:
    • KEY CLICK - short high click on every key press (ON/OFF)
    • LAYER TONE - two rising notes when the layer changes (ON/OFF)
    • START TONE - rising chirp at power-up (ON/OFF)
    • BEEP VOL - volume 0.1-1.0, with a test beep as you turn (passive buzzers only)
    • BUZZER - PASSIVE, ACTIVE or NONE; applies as soon as you save (NONE switches the buzzer off and hides SOUND)
  • Sounds: start-up chirp, timer alarm (repeats until dismissed), key click and layer-change tone. On an active buzzer the click and layer tone differ by rhythm instead of pitch.
  • Sounds play in the background, so the macropad never freezes while beeping.

Mouse Jiggle

Prevents your computer from going to sleep by moving the mouse cursor periodically.

Activating Jiggle

Hold encoder + turn clockwise (the default; any gesture can be set to TOG JIGGLE in GESTURES)

The display briefly shows "JIGGLE" and a "J" indicator appears in the top-right corner.

Deactivating Jiggle

Hold encoder + turn clockwise again

The "J" indicator disappears.

How It Works

  • Mouse moves 1 pixel in a random direction every 25-40 seconds
  • Movement is subtle and won't interfere with work
  • Immediately returns cursor to original position

Secret Layers

Up to two optional hidden layers, Secret 1 and Secret 2, that time out after 15 seconds of inactivity. Perfect for sensitive functions. They don't appear in the Layers menu or Layer Keys, and neither can be the home layer. In the Keymap Configurator, set a layer's Secret layer choice to Secret 1 or Secret 2 (one layer each).

Opening a Secret Layer

  • Secret 1: the TOG SEC 1 gesture (by default hold encoder + turn counter-clockwise)
  • Secret 2: the TOG SEC 2 gesture. It has no gesture by default: pick one in GESTURES, for example C+HOLD CCW.
  • If the keymap has only one of the two, both gestures open that one. With no secret layers, they do nothing.
  • From one secret layer you can go straight to the other with its gesture.

Leaving a Secret Layer

  • Wait 15 seconds without pressing a key or turning the encoder (automatic timeout, adjustable with SECRET T O in VARIABLES; the same for both)
  • Use the same gesture again

Either way, you go back to the regular layer you were on before (also after hopping between the two secret layers).

Variables Menu

Adjust timing, speeds, and timeouts to customize your macropad's behavior.

You can also change every setting from a computer with the Settings Editor.

Opening Variables

  1. Long press encoder → Settings menu
  2. Turn to VARIABLES and click to open

Navigating Variables

  • Turn encoder: Scroll through settings
  • Press: Edit the selected setting (shows its name top-left and value large)
  • Turn (while editing): Adjust value up/down
  • Press (while editing): Save and return to the list

Saved changes take effect immediately, no restart needed. The menu closes by itself after 30 seconds without input; a value you were still editing is discarded.

Note: Settings can only be saved when the macropad started normally (USB drive hidden). If you started it in programming mode by holding the encoder at power-up (or boot.py isn't on the drive), changes apply until the next restart but aren't saved, and the screen briefly shows NOT SAVED.

Available Settings

  • LONG PRESS - Duration for long press detection (0.5-3.0s)
  • MED PRESS - Duration for medium press detection (0.1-1.0s)
  • SECRET T O - Secret layer timeout, for both secret layers (5-60s)
  • LAYERS T O - Layers menu timeout (3-30s)
  • SETTINGS T O - Settings menu timeout (5-60s)
  • ENC SP FS - Encoder fast speed threshold: clicks closer together than this count as fast (0.01-0.1s)
  • ENC * FS - Fast rotation multiplier (1-10)
  • ENC SP MD - Encoder medium speed threshold (0.02-0.2s)
  • ENC * MD - Medium rotation multiplier (1-5)
  • RPT DELAY - How long to hold a key with "Repeat while held" before it starts repeating (0.1-2.0s, default 0.5s)
  • RPT RATE - How many times a second it then repeats (1-30, default 10)
  • CONFIRM T - How long to hold a hold-to-confirm key before it fires (0.2-3.0s, default 0.6s)
  • ROLL TIME - How long a menu takes to roll one item (0-0.4s, default 0.15s; 0 = off)
  • ROLL STEPS - Frames drawn during each roll (1-8, default 4; more = smoother, see Layers)

Buzzer and LED settings have their own SOUND and LIGHTS menus (see Add-ons).

  • RESET DFLT - Restore all settings to defaults (from default.js)
  • EXIT - Close the Variables menu

A few settings are only changed by editing settings.js directly (in programming mode): mouse jiggle timing (jiggle_min_interval, jiggle_max_interval, jiggle_max_pixels), display timings, the CONFIGURATOR/ABOUT links, loop_stats (prints main-loop timing to the serial console; see Troubleshooting), button_debounce (how long the encoder button must be steady before a press counts, default 0.03 s), encoder_reverse (set to true if the encoder is wired backwards), and the add-on hardware settings (led_count, buzzer, buzzer_active_low; see Add-ons).

Encoder Gestures

Double click, triple click, hold + turn and click-then-hold + turn (each direction) can each run a device function. They work the same on every layer.

Changing Gestures

Long press encoder → Settings → GESTURES. Turn to pick an item, press to edit, turn to change, press to save.

  • DOUBLE CLK - Double click (default LAYER KEYS)
  • TRIPLE CLK - Triple click (default TIMER)
  • HOLD CW - Hold + turn clockwise (default TOG JIGGLE)
  • HOLD CCW - Hold + turn counter-clockwise (default TOG SEC 1)
  • C+HOLD CW - Click once, then press and hold while turning clockwise (default STOPWATCH)
  • C+HOLD CCW - Click once, then press and hold while turning counter-clockwise (default NONE)
  • CLICK TIME - Longest gap between clicks of a double/triple click (0.15-0.6s, default 0.25s)
  • HOLD TURN - Encoder clicks needed for a hold + turn (1-10)
  • HOLD MIN - Minimum hold duration for a hold + turn (0.1-1.0s)
  • RESET DFLT / EXIT

Click Timing

  • After a click, the macropad waits up to CLICK TIME for another click before acting, so a single click opens the Layers menu a moment later than a press used to.
  • A triple click acts as soon as the third click is released.
  • A click-then-hold + turn counts only if the hold starts within CLICK TIME of the click; otherwise it's a plain hold + turn.
  • If TRIPLE CLK is NONE, a double click acts as soon as the second click is released. If DOUBLE CLK, TRIPLE CLK and both C+HOLD gestures are NONE, a single click opens the Layers menu instantly.
  • Inside menus, a click still selects instantly.

Keymap Configurator (Web Tool)

A web-based tool for customizing your key assignments without coding.

Opening the Configurator

  1. Visit: https://mp1-configurator.theornerymaker.com
  2. Or from Settings → CONFIGURATOR

The configurator, the settings editor, the macro recorder and this guide share a top bar with links between them. Auto / Light / Dark at the top right picks the colour scheme: Auto follows your computer's setting, and your choice is remembered in that browser. The pages work offline (no web fonts), so they look the same when opened from the CIRCUITPY drive.

Using the Configurator

  1. Load your keymap.js (optional). Version 1 files from older firmware are converted automatically, with a list of anything that changed.
  2. Pick a layer tab. The ◀ ▶ arrows either side of the selected tab move it left or right. Use + Add layer, Duplicate layer (adds a copy after the current one) and Delete layer to arrange layers. The order is the order in the Layers menu.
  3. Or start from a template: + Add layer from template… adds a ready-made layer to edit: Media (volume keys repeat while held), Editing (cut, copy, paste, undo…), Navigation (arrows, home/end, page up/down), Browser (back, reload, tabs…), Windows (snap left/right, maximise, task view, screenshot, lock; encoder = virtual desktops), Presenter (start, start here, black/white screen, slides, first, end; encoder = slides) or Numpad operators.
  4. Set the layer details: name (up to 10 characters), Home layer (active at power-up, exactly one) and Secret layer: Not secret, Secret 1 or Secret 2 (optional; one layer each, never the home layer; see Secret Layers).
  5. Check the screen preview. The monitor button next to the layer buttons opens it in a small panel that stays up while you edit (it remembers whether it was open). It shows the layer as it will look on the macropad's screen: icons cut to 4 characters, the encoder icon top left, and ERR on any key the macropad would reject. Click a key in the preview to jump to its settings.
  6. Rearrange keys by dragging: drag a key in the preview, or by its ⠿ Key N heading, onto another key to swap the two (icon, action, repeat and confirm settings move together).
  7. Set up each key (Key 1-4 is the top row, 5-8 the bottom row): an icon of up to 4 characters, plus one action:
    • Type text - types the text (a new line presses Enter)
    • Key - a single key, held for as long as you hold the macropad key
    • Key combo - up to 4 keys together, e.g. CONTROL + C
    • Media key - play/pause, tracks, volume, mute, brightness, etc.
    • Open URL - opens a website through the Windows Run box
    • Run app - runs a program through the Windows Run box (Win+R)
    • Mouse scroll - scrolls the wheel (positive = up)
    • Mouse move - moves the pointer by X/Y pixels
    • Mouse click - left, right or middle button, held while the key is held
    • Macro - a list of steps (any action above plus delays), each repeatable with ×N
    Any key with an action gets a Hold to confirm tick box: it then only fires after being held (see Hold-to-Confirm Keys). Media keys, scrolling, mouse moves, text and macros also get a Repeat while held tick box (see RPT DELAY / RPT RATE in the VARIABLES menu); a key can't have both.
  8. Set up the encoder (see below)
  9. Check the problems list in the Save section. It shows the same errors the macropad would report at start-up.
  10. Undo / Redo: the ↶ Undo and ↷ Redo buttons in the save bar (or Ctrl+Z and Ctrl+Y / Ctrl+Shift+Z) step back and forward through your edits, including added, deleted, moved and swapped layers and keys, and jump to the layer that changed. Typing in one box counts as one step. While the cursor is in a text box, Ctrl+Z undoes the typing in that box instead; click outside it to undo whole edits. Opening a keymap starts a fresh history.
  11. Print a cheat sheet: 🖨 Cheat sheet in the save bar at the bottom prints a summary of every layer: the 8 keys laid out like the pad with their icons and what they do, the encoder for each layer, and what the encoder button's clicks and gestures do. Choose Save as PDF in the print window for a file. Secret layers, the gestures that open them and long typed text are left out, so it's safe to leave on your desk. The gestures come from settings.js when the page is opened from the drive (otherwise the defaults).
  12. See what you've changed: keys changed since the keymap was opened (or last saved) get a purple edge, layer tabs with changes (or new layers) get a dot, and the save bar sums it up, including removed or reordered layers. Putting something back the way it was clears its mark. The page warns you before closing with unsaved changes.
  13. Save keymap.js with the buttons at the bottom of the page (they stay in view while you scroll):
    • Save to drive writes it straight to the connected CIRCUITPY drive (see below)
    • Or Save as…, then copy the file to the root of the drive yourself (not a sub-folder), in programming mode (hold the encoder button while plugging in)

Opening and Saving Files

The configurator and the settings editor open and save their file the same way:

  • Connect folder… (Chrome and Edge): pick the CIRCUITPY drive once. The browser remembers it, and may ask once per visit to allow editing.
  • Opened from the drive, the pages load your files by themselves: the configurator shows keymap.js and the settings editor shows settings.js (with the defaults from default.js) from the same folder, in every browser, with nothing to click. Without those files they start from their built-in defaults.
  • Open from drive / Save to drive: read or write keymap.js (or settings.js) in the connected folder directly; Open from drive falls back to keymap.json / settings.json if there's no .js file. Before saving, the old file is kept as keymap.js.bak / settings.js.bak.
  • Open file… / Save as…: pick any file or location yourself. Open file… accepts .js and .json; Save as… writes .js, or plain JSON if you give the file a .json name. These work in every browser; where the browser has no save dialog (Firefox, Safari), Save as… downloads the file instead. The drive buttons only appear in browsers that support them.
  • The copy button on the JSON box in the Save section copies the plain JSON (what keymap.json / settings.json would hold). To save plain JSON instead of .js, use Save as… and give the file a .json name.
  • The CIRCUITPY drive has to be visible and writable: start the macropad while holding the encoder (programming mode). The macropad restarts by itself after a save and uses the new file straight away.

Encoder Setup

Each layer has its own encoder icon and two actions: one for clockwise and one for counter-clockwise. Any key action works on the encoder.

  • Presets fill in both directions: Volume, Scroll, Zoom, Next/previous track, Browser tabs, Redo/undo, Arrow keys, Page up/down, Screen brightness, Mouse move.
  • Speed up when turned fast repeats the action more times on fast spins (amounts set by ENC * FS / ENC * MD in VARIABLES). Use it for volume, scrolling and arrows; leave it off for tabs, tracks or undo.
  • Swap directions flips clockwise and counter-clockwise.

Layer Lights

The LIGHTS settings (scene and colours) are used on every layer. A layer can have its own scene and colours (palette colours or a custom colour): while that layer is active they replace the LIGHTS settings, and switching to a layer without its own lights goes back to the LIGHTS settings. Brightness and speed always come from the macropad's LIGHTS menu.

When the page is opened from the drive and the macropad's settings say no LED strip is fitted (LED count 0, the default), the Lights section is hidden; Show anyway brings it back, and lights already set on a layer stay in the keymap.

Macros

  • + Add step adds a step; ▲ ▼ reorder, ✕ removes, and ×N repeats a step N times
  • ● Record / ● Record more records keystrokes into the macro (see Recording Macros); an empty key has ● Record macro
  • Paste JSON adds steps as JSON, e.g. copied from another key (output from the old Macro Recorder page still works)

Saving, Loading and Copying a Key

Each key card has three small buttons at the top right:

  • Export key (disk icon) saves the key as ICON.mp1key.json, e.g. SEND.mp1key.json, to share one key or macro with another macropad.
  • Import key (folder icon) puts an exported key into this key, asking first if the key isn't empty. Undo takes it back.
  • { } shows the key as text, e.g. {"icon": "CPY", "combo": ["CONTROL", "C"]}. ⧉ Copy copies it; edit the text or paste a key in and press Apply. Handy for copying a key to another layer.

A key keeps everything: icon, action or macro, hold-to-confirm and repeat. Saving a key from a secret layer asks first, because the file contains what it types as plain text.

Sharing Layers Between Macropads

Pass a whole layer (all 8 keys, the encoder and any macros) to another macropad, for example a set of keys for filling in a complex form. The buttons are next to the templates:

  • Export layer (disk icon) saves the selected layer as NAME.mp1layer.json to send or keep.
  • Import layer (folder icon) on the other macropad's configurator adds a layer from such a file.
  • { } shows the selected layer as text. ⧉ Copy copies it to paste into an email or chat message. To import a layer someone sent you as text, replace the text in the box with theirs and press Import as new layer (the selected layer isn't changed).
  • An imported layer is added as a new layer at the end (it never replaces anything), the page switches to it, and a note lists anything that was adjusted. Check it, then save the keymap as usual. Undo takes the import back.

What happens to device-specific details:

  • Layer lights are exported, but left out on import when the receiving macropad has no LED strip (its settings say LED count 0). If the page can't see that macropad's settings (not opened from its drive), they're kept; a macropad without a strip ignores them anyway.
  • Default and secret are never carried over: an imported layer is a regular layer, so it can't change which layer starts up or take over a secret slot. Exporting a secret layer asks first, because the file contains what its keys type as plain text.
  • Same name: if the macropad already has a layer with that name, the imported one gets a number (FORMS → FORMS2).
  • Hold-to-confirm, repeat, macros and the encoder all come across unchanged. Importing a whole keymap file (keymap.js / keymap.json, version 1 too) adds all its layers after asking. The configurator holds up to 10 layers.

Settings Editor (Web Tool)

Open settings_editor.html from the CIRCUITPY drive (or Settings in the top bar of any of the web pages) to edit settings.js on a computer: every setting the macropad has, including the ones only settings.js has.

  • Settings are grouped like the device's menus: Gestures, Variables, Screen, Lights, Sound, plus Encoder hardware, Mouse jiggle and Advanced. The sidebar on the left jumps to each section, highlights the one you're in, and shows how many settings you've changed in each.
  • Add-on settings only appear when the add-on is fitted, like the LIGHTS and SOUND menus on the macropad: the LED strip settings (and LEDs off with the screen) once LED count is above 0, and the sound settings once a Buzzer type is picked (beep volume for passive buzzers only, "sounds on low" for active ones only). Hidden settings keep their values and are still saved.
  • Each setting shows where it is on the macropad (for example VARIABLES › LONG PRESS), or settings.js if it has no menu item, and its default.
  • Settings you've changed since opening the file get a purple edge, and the sidebar and the save bar count them (with nothing opened, the defaults are what you started from). ↺ undo puts one back to the file's value; default (shown when a value differs from the default) sets it to the default, and Reset all to defaults does that for every setting. After saving, the saved values are the new starting point.
  • It checks your values like the macropad does at start-up. A value outside the menu's usual range is a warning (the macropad still accepts it). Settings missing from a file you open use their default, and unknown settings are left out.
  • The saved file has every setting, one per line, in the same layout the macropad writes itself.
  • Open and save it with the same buttons as the configurator (see Opening and Saving Files).

keymap.js Format

The configurator writes this for you, but the file is easy to read and edit by hand. It's plain JSON on one script line, var MP1_KEYMAP = { ... };, so the web pages beside it on the drive can load it automatically (browsers let a page load a script from its folder, but not read a .json file there). Each layer keeps all its information together:

// MP1 macropad keymap. Edit with keymap_configurator.html (the JSON inside is the same as keymap.json).
var MP1_KEYMAP = {
  "version": 2,
  "layers": [
    {
      "name": "MEDIA",
      "default": true,
      "keys": [
        {"icon": "PLY", "media": "PLAYPAUSE"},
        {"icon": "VOL+", "media": "VOL_UP", "repeat": true},
        {"icon": "OFF", "combo": ["WINDOWS", "X"], "confirm": true},
        {"icon": "HI",  "text": "Hello"},
        {"icon": "WEB", "url": "https://example.com"},
        {"icon": "NOTE", "app": "notepad.exe"},
        {"icon": "MAC", "sequence": [{"key": "A"}, {"delay": 0.1}, {"text": "done"}]},
        {"icon": "---"}
      ],
      "encoder": {"icon": "VOL", "cw": {"media": "VOL_UP"}, "ccw": {"media": "VOL_DN"}, "accel": true},
      "lights": {"scene": "breathing", "color1": "BLUE", "color2": "#FF8800"}
    },
    {"name": "VAULT", "secret": true, "keys": [{"icon": "PW", "text": "hunter2\n"}]},
    {"name": "VAULT2", "secret": 2, "keys": [{"icon": "PIN", "text": "1234"}]}
  ]
};
  • Layer fields: name, default (true on one layer), secret (optional: true or 1 = Secret 1, 2 = Secret 2; one layer each), keys (up to 8), encoder
  • Keys: an icon plus exactly one action. null is an empty key; {"icon": "---"} is a label with no action.
  • Repeat while held (optional): "repeat": true on a key with a media, scroll, mouse, text or sequence action fires it again and again while the key is held, after RPT DELAY and at RPT RATE (VARIABLES menu). Not needed for key, combo or click: those are held down while you hold the key, so the computer repeats them itself like a normal keyboard. The start-up check reports repeat on any other action.
  • Hold to confirm (optional): "confirm": true on any key with an action makes it fire only after being held for CONFIRM T (see Hold-to-Confirm Keys). Not together with repeat.
  • Actions: text, key, combo, media, url, app, scroll (wheel clicks, + is up), mouse ([x, y] pixels), click ("left", "right" or "middle"), sequence (a macro: a list of actions), delay (seconds, inside sequences)
  • Media names: PLAYPAUSE, NEXT, PREV, STOP, FAST_FORWARD, REWIND, MUTE, VOL_UP, VOL_DN, EJECT, BRIGHTNESS_UP, BRIGHTNESS_DOWN
  • Encoder: icon, cw (clockwise action), ccw (counter-clockwise action), accel (speed up on fast spins)
  • Lights (optional): scene (static, breathing, reactive, pulse, twinkle, lightning, strobe, rainbow, cycle, off), color1, color2. Colours are palette names (RED, VERMILION, ORANGE, AMBER, YELLOW, LIME, GREEN, MINT, CYAN, SKY, BLUE, INDIGO, PURPLE, MAGENTA, PINK, ROSE, WHITE, WARM_WHITE) or "#RRGGBB".
  • Device behavior (timings, timeouts, encoder speed) belongs in settings.js, never in keymap.js.
  • Editing by hand: change only what's between the first { and the last }; leave the var MP1_KEYMAP = line start and the final ; alone. settings.js and default.js work the same way (MP1_SETTINGS, MP1_DEFAULTS).
  • Plain .json still works: the macropad reads keymap.json, settings.json and default.json if there's no .js file of the same name (if both are there, the .js file wins). The macropad itself saves settings.js.

Start-up Error Check

At power-up the macropad checks keymap.js and settings.js. If anything is wrong, it shows an error screen instead of crashing:

  • The top line shows ERROR 1/3 press=OK, followed by the problem and where it is, e.g. MEDIA key 3: unknown key CTRL
  • Turn the encoder to step through the errors; press to continue
  • A key with a problem shows ERR as its icon and does nothing; the rest of the layer works normally
  • A macro with a bad step is disabled entirely rather than run partway
  • If keymap.js is missing, unreadable, or still in the version 1 format, the macropad starts with an empty NO KEYMAP layer. Menus, timer and jiggle still work.
  • Bad values in settings.js are reported and replaced by their defaults
  • If an add-on (LED strip or buzzer) is switched on in settings.js but fails to start, it's reported and the macropad carries on without it

Watchdog (Automatic Restart)

If the macropad ever freezes completely, a hardware watchdog restarts it after about 8 seconds, so it never needs unplugging. Normal use never trips it: the firmware checks in with the watchdog constantly, including during pauses, long macros and long typed text.

  • After a watchdog restart, the start-up error screen says so. If it keeps happening, note what you were doing at the time (which key, which layer).
  • A key or macro that was running when it froze may not have finished, and keys that were held down are released by the restart.
  • Pressing Ctrl+C in the serial console turns the watchdog off, so ledtest, enctest and the >>> prompt work normally. Ctrl+D restarts the macropad with it back on.
  • To turn it off, set "watchdog": false in settings.js and restart.

Errors While Running

  • If something goes wrong while the macropad is running, it releases every key and mouse button (so nothing stays stuck), shows Runtime error: … on the same error screen, and keeps working after you press the encoder

Fix the file in the Keymap Configurator (load it, check the problems list, download it again).

Recording Macros

The macro recorder is built into the Keymap Configurator: it records keystrokes straight into a key's macro, with nothing to copy or paste.

Recording

  1. On an empty key, click ● Record macro. (On a key that's already a Macro, click ● Record, or ● Record more to add onto the end.)
  2. The recorder opens and is already recording: the red border pulses. Type the macro. Each key shows up as a step while you type: Types "hello", Tab, Ctrl + C, Enter…
  3. Stop with the ■ Stop button or by holding Esc for 1 second (a quick Esc tap is recorded as Esc). Switching to another window also stops it. ● Record carries on from where you stopped.
  4. Pick the Pauses (you can change this after recording and the steps update straight away):
    • None: no waiting between steps
    • After keys (default): a short wait, 0.05 s unless you change it, after each key or combo, so the computer has time to react (e.g. a Tab moving to the next box)
    • As recorded: the pauses you made while recording (gaps under 0.25 s count as normal typing)
  5. ⌫ Last step takes back the last step. Done keeps the recording; Discard throws it away (a key that had no action goes back to none).

What gets recorded

  • Typing becomes one Type text step. Shift is part of the character, so capitals and symbols just type.
  • Keys held with Ctrl, Alt or Win become a Key combo, e.g. Ctrl + Shift + T. A modifier pressed on its own (just Ctrl) is recorded as that key.
  • Holding a key down records it once; the same key pressed several times in a row becomes one step with ×N.
  • Keys the macropad can't send (accented letters typed with dead keys, media keys and so on) are skipped, with a note.
  • Windows and the browser keep some keys to themselves and the page never sees them: the Windows key, Alt+Tab, Ctrl+Alt+Del, and browser shortcuts like Ctrl+W, Ctrl+T or Ctrl+N. Add those afterwards with + Add step → Key combo.

After Done the steps are an ordinary macro: reorder them, change a ×N, edit a wait or add steps by hand. The whole recording is one step for Undo.

Tips & Tricks

Avoid Locking Yourself Out

Always keep at least one key as TAB or ENTER so you can navigate if something goes wrong.

Layer Organization

  • Layer 1 (default): Most frequently used actions
  • Secret layer: Sensitive credentials
  • Other layers: Organized by context (work, media, gaming, etc.)

Encoder Functions

Make your encoder context-aware (each layer has its own; see Encoder Setup):

  • Work layer: Zoom in/out or redo/undo
  • Media layer: Volume control or next/previous track
  • Browser layer: Scroll or tab switching
  • Editing layer: Arrow keys to step through text or timelines

Timeout Adjustments

  • Short timeouts (3-5s): Faster workflow, less accidental triggers
  • Long timeouts (10-30s): More forgiving, better for browsing

File Management

  • Always backup keymap.js before making changes
  • Keep default.js safe - it's your reset point
  • settings.js stores your timing preferences

Macro Best Practices

  • Add small delays (50-100ms) between actions for reliability
  • Test macros on non-critical tasks first
  • Use TAB instead of mouse clicks when possible (more reliable)

Troubleshooting

Nothing starts; the serial console shows MemoryError:

  • The macropad ran out of memory while loading. Make sure every file in lib/macropad/ came from the same firmware version (old and new files mixed can load extra code), and remove any old files that aren't in the file list.
  • A very large keymap.js (many layers with long text or macros) uses more memory. The serial console prints Free memory at start-up; above roughly 20,000 bytes is comfortable.

Keys not working / key shows ERR:

  • Restart the macropad and read the start-up error screen
  • Check that keymap.js is in the root of the CIRCUITPY drive
  • Load the file in the Keymap Configurator and check its problems list

Hold + turn gestures don't work, or run the wrong one:

  • Keep the encoder pressed for the whole turn and turn at least HOLD TURN clicks (GESTURES menu, default 5). Lower it if 5 feels like a lot.
  • The direction is the way the encoder turned overall, so a click of wobble as you stop doesn't change it. A brief flicker in the button contact while you turn (under 0.08 s) is ignored.
  • To see exactly what the macropad detects, set "debug_gestures": true in settings.js, restart, and open the serial console (Mu, Thonny or similar). Each press prints a line like:
    button: held 651 ms, turned 6 clicks (net -6), contact flickers 0, mode 0, clicks before 0 -> gesture_hold_ccw = jiggle
    turned = all clicks, net = clockwise minus counter-clockwise, contact flickers = how often the button contact briefly opened while held. Set it back to false when done. With debug on, every encoder click also prints its position, so you can see each click's direction.
  • To test the encoder on its own: in the serial console press Ctrl+C, then any key for the >>> prompt, and type import enctest. Turn a few clicks each way, with and without the button pressed. enctest.raw() shows the A/B pin levels instead. Ctrl+D restarts the macropad.

Encoder skips clicks, or sometimes counts the wrong way:

  • Check the encoder's power and ground wires first. A loose VCC (+) or GND wire between the board and the encoder causes random missed clicks, phantom clicks and wrong-way steps, often worse when the encoder is pressed.
  • Only every other click registers (in normal turning too): the encoder moves 2 pin steps per click instead of the usual 4. Check with enctest.counted(2) in the serial console: if every click now counts exactly 1, set "encoder_divisor": 2 in settings.js and restart.
  • A click registers when you press or release the encoder: pressing rocks the shaft enough to move some encoders. The firmware ignores encoder movement for encoder_press_guard seconds after the button contact changes (settings.js, default 0.06; raise it a little if it still happens, 0 turns it off).
  • Random missed clicks or wrong-way steps, worst while pressing the encoder: the encoder's contacts are bouncing (electrically noisy). The firmware can't filter this; it's fixed in hardware with a small filter on each encoder pin:
    • a 10 kΩ resistor from A to 3.3V and from B to 3.3V (the RP2040's built-in pull-ups are weak), and
    • a 0.01 µF (10 nF) capacitor from A to GND and from B to GND, close to the encoder. Up to 0.1 µF is fine for a hand-turned encoder.
    Many encoder breakout boards (e.g. KY-040) already have the resistors but not the capacitors. Keep the encoder's ground wire short and solid; a poor ground makes bounce much worse.

Screen is blank or dim, or a key press did nothing:

  • The screen saver has dimmed or switched off the screen. Press any key or the encoder to wake it. While the screen is off, that first press only wakes it.
  • Change the timing or turn it off in Settings → SCREEN.

Screen shows NO KEYMAP:

  • keymap.js is missing, not valid JSON, or still in the version 1 format. Load it in the Keymap Configurator (it converts version 1 files), download it again, and copy it to the drive.

Timer not visible:

  • Timer shows in top bar on all layers
  • Only visible when timer is running or set

Encoder feels unresponsive:

  • Adjust encoder speed settings in VARIABLES menu
  • Check that you're not in a menu (medium press to exit)

Macropad feels sluggish or stutters:

  • Set "loop_stats": true in settings.js and open the serial console. Every 5 seconds it prints a line like loop: 4100 passes/5s, avg 0.20 ms, slowest 23.5 ms, free memory 98000 bytes. The slowest pass is usually a screen update; occasional spikes of a few ms are memory clean-up. Set it back to false when done.
  • The OLED runs at 400 kHz (I2C_FREQUENCY in wiring.py). If the screen shows glitches or garbage, set it back to 100000.

Encoder action goes the wrong way on one layer:

  • In the Keymap Configurator, open that layer and click Swap directions

Everything on the encoder is reversed (menus, gestures and actions):

  • The encoder is wired the other way round. Set "encoder_reverse": true in settings.js (and default.js, so RESET DFLT keeps it).

Settings reset on power cycle:

  • Settings must be saved to settings.js
  • Use VARIABLES menu to adjust and save
  • Saving only works when the macropad started normally, not in programming mode (USB drive visible)

LED strip dark:

  • Set "led_count" in settings.js to the number of LEDs (e.g. 4) and make sure lib/neopixel.mpy is on the drive
  • Check that the LIGHTS scene isn't OFF and BRIGHTNESS isn't at its lowest
  • Open the serial console (Thonny, Mu or any serial terminal). At start-up the macropad prints LED strip: started, 4 LEDs on board.GP19… and then LED strip: first colour sent…; a failure is printed there too.
  • Run the standalone LED test: in the serial console press Ctrl+C, then Enter, then type import ledtest. Each LED should light red, green, blue and white in turn, then all orange. If nothing lights, check the strip's power, ground and data wiring to GP19. Ctrl+D restarts the macropad afterwards.

Buzzer silent:

  • Set "buzzer" in settings.js to "passive" or "active", and check it's wired + to GP17 and – to GND
  • An active buzzer that's on all the time (or never) may need "buzzer_active_low": true
  • Key click and layer tone are off by default; turn them on in SOUND

Mouse jiggle not working:

  • Check for "J" indicator in top-right
  • Some systems may ignore very small movements
