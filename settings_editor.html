Settings Editor

Edit settings.js: how the macropad behaves. The same settings as the device's menus, plus the ones only the settings file has.

Open settings

No drive folder
Opened from the CIRCUITPY drive, this page loads settings.js from beside it automatically. Or start from the defaults below, or open a settings.js / settings.json file. Settings missing from a file use their default.

Save settings

The macropad restarts by itself when settings.js changes on its drive, and uses the new settings straight away. To copy it by hand: start the macropad while holding the encoder so the CIRCUITPY drive appears, then put settings.js in the root of the drive. The text below is the plain JSON (what Copy JSON gives you, and what Save as… writes for a .json name); settings.js is the same JSON on one extra line.
