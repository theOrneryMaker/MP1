Starter keymap for the MP1 firmware package.

keymap.js here is a generic keymap with six ready-made layers:
  MEDIA (home layer), EDIT, NAV, BROWSER, WINDOWS, PRESENT
No secret layers and no personal text. Built from the Keymap Configurator's templates.

When putting together a firmware package to share, use THIS keymap.js,
not the one in FIRMWARE_00 (that's a personal keymap).
